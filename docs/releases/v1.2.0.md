# YTCache 1.2.0

Capture a YouTube video while it plays, then watch it offline — full-screen, swipeable, with the
video's real length on the seek bar.

## What changed

### The player tells the truth about time
- The seek bar now spans the **real duration** of the video, not the length of the capture. A
  10-minute cache of a 40-minute video looks like a 40-minute video.
- The cached part is drawn as a **band** on that bar, and a chip reads `Cached 12:34–24:10 / 45:00`.
- **Auto-align:** playback starts at your saved position when it is inside the cached window,
  otherwise at the first cached frame — no more sitting at 0:00 on a mid-video capture.
- Seeking outside the cached window snaps to the nearest cached frame and tells you the window.
- Remaining time is counted against the real duration.

### YouTube-style fading chrome
- Title, channel, actions and controls fade out after ~2.6 s of playback and come back on tap,
  pause or seek. They no longer cover the bottom of every video permanently.

### A back button that works on YouTube
- Fullscreen video → close it.
- YouTube's own in-page history (via a new `pushState`-aware bridge) → go back one screen.
- WebView history → go back a page.
- Otherwise *Press back again to exit* (2.2 s window).

### Extras
- Tap ripple on the player surface.
- The last video you watched is restored when you reopen the player.
- Fixed time listeners that could leave the clock and bar stale.

## Also in this build (from 1.1.x)
- Lossless export to MP4/WebM with sound, or audio-only; honest message when a codec pair has no
  legal container.
- Library search and sorting (newest / oldest / largest / A–Z), multi-select batch export and delete.
- Metadata and thumbnail captured at cache time, so the library works with no connection.

## Install

```bash
adb install -r YTCache-1.2.0-release.apk
```

Android 8.0+ (API 26), package `com.ytcache.app`, signed with the project key `CN=YTCache`.
`YTCache-1.2.0-debug.apk` is the same code with the debug signature — only use it if a device
refuses the release signature (different keys cannot upgrade each other; uninstall first).

## Intended use

Cache content you are allowed to keep. No DRM is circumvented. Downloading copyrighted video may
violate YouTube's Terms of Service and local law.
